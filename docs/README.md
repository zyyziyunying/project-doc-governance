# Skill Docs

This repository keeps docs intentionally simple.

## Layout

- `docs/product/`: what to build
- `docs/design/`: technical design
- `docs/check/`: validation and acceptance
- `docs/plan/`: execution plan
- `docs/status/`: current status
- `docs/problem/`: active problems
- `docs/discussion/`: open discussion

Each category keeps its own `archive/`.

## Placement Rules

- Put active docs in the matching category
- Move old docs into that category's `archive/`
- Keep reusable templates in `references/`
- Root `README.md` is overview only
